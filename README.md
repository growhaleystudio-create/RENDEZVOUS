# Rendezvous Landing Page

Editorial marketing site and booking prototype for Rendezvous barbershop. Built with Astro, React, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

Astro serves the site at `http://localhost:4321` by default.

## Checks

```sh
npm test
npm run build
```

## Project structure

- `src/pages/` — homepage, booking demo, and service, branch, barber, and journal pages
- `src/components/` — reusable site sections and interactive components
- `src/data/` — demo content, lookbook items, and booking data
- `src/styles/` — global, campaign, typography, and motion styles
- `public/images/` — optimized images used by the site
- `docs/` — design and implementation notes

Booking is a front-end prototype. It does not create a confirmed appointment or process payment.
